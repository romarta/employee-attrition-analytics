# Employee Attrition & Retention Analytics # 

> **🚧 Work in Progress** — This project is currently under development.

An end-to-end HR analytics portfolio project using Power BI, Python, and Quarto to explore employee attrition patterns, investigate associated workplace factors, and support evidence-based retention decisions.

## Business Objective ##
Identify where employee departures are concentrated, which characteristics are associated with higher attrition, and which areas HR should prioritize for further investigation and action.

## Planned Power BI Analysis ##
1. Executive Overview — Workforce snapshot and attrition patterns across departments and job roles.
2. Attrition Drivers Discovery — Explore potential influencing factors and employee segments using Key Influencers and Decomposition Tree (two bookmark-based views).
3. Attrition Drivers Analysis — Validate patterns through group comparisons, DAX measures, and analysis across departments.
4. Employee Experience — Examine satisfaction and performance-review data for current employees using quality-checked records.
5. Retention Strategy — Prioritize areas for action and explore illustrative What-if scenarios.
A supporting Data Quality & Methodology page will document validation checks, exclusions, and analytical limitations.

## Data Quality and Limitations ##
The dataset includes employee records, performance reviews, and lookup tables.

The analysis will explicitly address reviews dated before employee hire dates, ambiguous training counts, and missing employee exit dates.

These limitations affect which records and metrics can be used. In particular, the project will not report annual turnover rates or treat observed associations as proof of causation.

## Tools and Planned Deliverables ##
- Power BI / Power Query / DAX: Data preparation, modeling, interactive dashboard, and analysis.
- Python: Data validation and selected statistical checks.
- Quarto: A concise, reproducible PDF report covering objectives, methodology, findings, limitations, and business recommendations.
